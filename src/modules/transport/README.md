# Transport Module (`src/modules/transport/`)

## Domain Scope

Manages school bus fleets, transport routes, pickup/drop-off stops, vehicle drivers, and student passenger allocations.

## Planned Responsibilities

- Vehicle asset management and driver credentials
- Route configuration with pickup points and designated pickup timings
- Student route subscriptions and transport fee associations
