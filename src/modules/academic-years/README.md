# Academic Years Module (`src/modules/academic-years/`)

## Domain Scope

Manages academic sessions, academic calendars, terms, semesters, and session transition lifecycles.

## Planned Responsibilities

- Academic year definitions (e.g. 2026/2027)
- Terms / semesters breakdown with start and end dates
- Current active academic session resolution
- Academic year rollover validations
