# Branches Module (`src/modules/branches/`)

## Domain Scope

Supports multi-campus or multi-branch educational organizations operating under a parent school institution.

## Planned Responsibilities

- Branch / campus creation and configuration
- Branch contact details and physical address mapping
- Scope queries to specific branches under the authorized school tenant
