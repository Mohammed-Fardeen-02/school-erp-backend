# Subjects Module (`src/modules/subjects/`)

## Domain Scope

Manages academic subjects, elective courses, subject codes, syllabi, and assignment to classes.

## Planned Responsibilities

- Subject catalog (core vs elective subjects)
- Subject credit units and grading weightage
- Mapping subjects to classes and assigned teachers
