# Timetable Module (`src/modules/timetable/`)

## Domain Scope

Schedules school periods, master timetables, teacher schedules, room allocations, and substitution management.

## Planned Responsibilities

- Bell schedules, period definitions, and break intervals
- Class-wise weekly master timetable
- Teacher clash prevention and availability matrices
- Teacher substitution management on leave
