# Guardians Module (`src/modules/guardians/`)

## Domain Scope

Manages parent and legal guardian profiles, emergency contact records, and relationships to enrolled students.

## Planned Responsibilities

- Guardian profile details (name, occupation, relationship, contact information)
- Mapping multiple students to a guardian (family account grouping)
- Portal access authorization for parents/guardians
