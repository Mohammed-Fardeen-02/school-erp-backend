# Inventory Module (`src/modules/inventory/`)

## Domain Scope

Manages school equipment, physical assets, stationery supplies, purchase orders, vendor contracts, and asset depreciation.

## Planned Responsibilities

- Item categories, stock levels, minimum threshold alerts
- Vendor management and purchase orders
- Item allocation to departments, classrooms, or staff members
