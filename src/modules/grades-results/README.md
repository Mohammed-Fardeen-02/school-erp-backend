# Grades & Results Module (`src/modules/grades-results/`)

## Domain Scope

Manages assessment scores, marks entry, grade calculations, student report cards, and academic ranking.

## Planned Responsibilities

- Teacher score entry and moderation workflows
- GPA / percentage aggregation based on academic grading scales
- Automated digital report card generation
- Class performance transcripts and merit lists
