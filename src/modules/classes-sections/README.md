# Classes & Sections Module (`src/modules/classes-sections/`)

## Domain Scope

Manages school grade levels, classrooms, streams/sections, student enrollment capacity, and class teacher assignments.

## Planned Responsibilities

- Class definition (e.g. Grade 1 to 12)
- Section division (e.g. Grade 10-A, 10-B)
- Capacity limits, classroom room assignments
- Class teacher / form tutor assignments
