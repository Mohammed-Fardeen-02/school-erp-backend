# Payroll Module (`src/modules/payroll/`)

## Domain Scope

Manages staff salary structures, allowances, deductions, payslip generation, tax calculations, and disbursement records.

## Planned Responsibilities

- Salary grade and pay scale definitions
- Monthly payroll processing linked to staff attendance records
- Deductions (tax, pension, loan repayments) and bonuses
- Digital payslip generation and distribution
