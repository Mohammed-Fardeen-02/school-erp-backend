# Reports Module (`src/modules/reports/`)

## Domain Scope

Aggregates analytical queries, operational reporting, compliance summaries, and tabular data exports (PDF, Excel, CSV).

## Planned Responsibilities

- Academic performance summaries
- Fee collection and outstanding balance ledgers
- Student attendance analytics
- Demographic and statutory compliance reports
